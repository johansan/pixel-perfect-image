# Contributing

Pixel Perfect Image is maintained by a single author. Pull requests from outside contributors are not accepted. Ideas
are welcome through GitHub issues.

## Bug Reports

Search the [existing issues](https://github.com/johansan/pixel-perfect-image/issues) before opening a
[new issue](https://github.com/johansan/pixel-perfect-image/issues/new). Include the Obsidian version, plugin version,
operating system, reproduction steps, relevant image or link syntax, and any themes or plugins that may affect the
behavior.

## Feature Requests

Search the [existing issues](https://github.com/johansan/pixel-perfect-image/issues) first, then open a
[new issue](https://github.com/johansan/pixel-perfect-image/issues/new) describing the use case and the behavior you
would like to see.

## Questions And Discussion

General questions and discussion happen through [GitHub issues](https://github.com/johansan/pixel-perfect-image/issues).

## Security Issues

Do not publish vulnerability details in a public issue. Open an issue asking for a private reporting channel without
including exploit details.

## Pull Requests

Pull requests are not accepted. They may be closed without review. Bug reports and feature requests through GitHub
issues are the supported way to influence the project.
